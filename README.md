# IoT-Based-Home-Security-System
IoT-Based Home Security System using ESP32 and a PIR motion sensor with real-time motion detection and mobile notifications through the KiwisIoT platform.
IoT-Based Home Security System Using ESP32 and KiwisIoT
About the Project
The IoT-Based Home Security System is an IoT-based smart home project designed to improve home safety by detecting unauthorized movement and providing real-time security alerts.

Using an ESP32 microcontroller and a PIR motion sensor, the system detects human movement inside or around the home. When motion is detected, the system sends instant notifications to the user's mobile through the KiwisIoT platform over Wi-Fi, allowing homeowners to monitor security events remotely.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to smart home security, motion detection, and remote monitoring.
